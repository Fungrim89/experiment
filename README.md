# 3D-Тренажёр фармацевта · «Супрадин» 🟠☀️

Обучающая **3D-игра** на **Three.js** — тренажёр фармацевта по линейке
витаминно-минеральных комплексов «Супрадин». Вы стоите за стойкой аптеки от
первого лица: посетители входят с улицы, подходят к прилавку и излагают запрос
на витаминную поддержку. Ваша задача — задать верные вопросы и подобрать
подходящий продукт. Персонаж реагирует на ваш ответ (кивает или качает головой).

## Запуск

Игра использует ES-модули (Three.js), поэтому её нужно открывать **через
локальный сервер** — при открытии файла напрямую (`file://`) браузер заблокирует
модули. Three.js завендорен в `js/vendor/`, так что интернет не требуется.

```bash
# из папки игры
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Любой другой статический сервер тоже подойдёт (`npx serve`, расширение
«Live Server» в VS Code и т. п.). Сборка не нужна.

## Технологии

| Слой | Решение | Почему |
|---|---|---|
| 3D | **Three.js r161** (ES-модуль, локально) | стандарт для WebGL, без сборки, офлайн |
| Логика/UI | чистый JS + CSS-оверлей | ноль зависимостей, мгновенный старт |
| Данные | JS-объекты (`products.js`, `scenarios.js`) | легко расширять линейку и кейсы |

Сцена (`scene.js`) строит интерьер аптеки, низкополигональных посетителей и все
анимации; игровой движок (`game.js`) управляет диалогом, баллами и оркеструет
сцену. UI вынесен в HTML-оверлей поверх `<canvas>`.

## Геймплей

Каждый посетитель — **3 решения**:

1. **Уточнение запроса** — какой вопрос уместно задать (возраст, симптомы,
   «красные флаги», текущий приём добавок).
2. **Рекомендация** — какой продукт линейки «Супрадин» предложить.
3. **Совет по приёму** — как принимать и о чём предупредить.

После каждого выбора — **профессиональный разбор**, посетитель реагирует, а в
конце смены показываются баллы, оценка и разбор по каждому посетителю. Рекорд
сохраняется в браузере. Кнопка **📖 Справочник** открывает карточки всей линейки.

## Чему учит

- Сопоставление продукта с **возрастом** и **задачей** (энергия, иммунитет,
  память и внимание, аппетит, общая поддержка).
- Распознавание **«красных флагов»**: беременность, высокая температура,
  длительные жалобы — повод направить к врачу.
- Безопасность: **не превышать дозу**, **не совмещать** несколько
  поливитаминов, принимать **во время еды**.

## Структура проекта

```
index.html             # разметка, importmap, оверлей UI
css/styles.css          # оформление в брендовой палитре
js/vendor/three.module.js  # Three.js r161 (завендорен локально)
js/scene.js             # 3D-сцена: интерьер, персонажи, анимации
js/game.js              # игровой движок (ES-модуль)
js/products.js          # справочник линейки (данные)
js/scenarios.js         # сценарии-кейсы посетителей (данные)
```

Контент носит **обучающий характер**, упрощён для тренажёра и не заменяет
инструкцию производителя и консультацию врача.
