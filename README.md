# Тренажёр фармацевта · «Супрадин» 🟠☀️

Обучающая веб-игра для тренинга фармацевтов по линейке витаминно-минеральных
комплексов **«Супрадин»**. К стойке подходят разные посетители со своими
запросами на витаминную поддержку — задача игрока выслушать, задать верные
уточняющие вопросы и подобрать подходящий продукт линейки.

## Как запустить

Никакой сборки не требуется — это статическая страница.

```bash
# Вариант 1: просто открыть файл
open index.html        # macOS
xdg-open index.html    # Linux

# Вариант 2: локальный сервер
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Геймплей

Каждый посетитель — это **3 решения**:

1. **Уточнение запроса** — какой вопрос уместно задать (возраст, симптомы,
   «красные флаги», текущий приём добавок).
2. **Рекомендация** — какой продукт линейки «Супрадин» предложить.
3. **Совет по приёму** — как правильно принимать и о чём предупредить.

После каждого выбора показывается **профессиональный разбор** — почему вариант
верный или нет. За верные решения начисляются баллы, в конце смены — итоговая
оценка и разбор по каждому посетителю. Рекорд сохраняется в браузере.

Кнопка **📖 Справочник** в любой момент открывает карточки всей линейки.

## Чему учит

- Сопоставление продукта с **возрастом** и **задачей** (энергия, иммунитет,
  память и внимание, аппетит, общая поддержка).
- Распознавание **«красных флагов»**: беременность, высокая температура,
  длительные жалобы — повод направить к врачу.
- Безопасность: **не превышать дозу**, **не совмещать** несколько
  поливитаминов, принимать **во время еды**.

## Структура проекта

```
index.html        # разметка и точка входа
css/styles.css    # оформление в брендовой палитре
js/products.js    # справочник линейки (данные)
js/scenarios.js   # сценарии-кейсы посетителей (данные)
js/game.js        # игровой движок
```

Контент носит **обучающий характер**, упрощён для тренажёра и не заменяет
инструкцию производителя и консультацию врача.
